### 2. 修改 API 层加载历史
- **文件**: `api/chat.py`
- **修改位置**: 步骤1后插入步骤1.5
- **新增代码**:
  ```python
  # ============ 步骤 1.5：加载历史消息 ============
  conversation_history = []
  try:
      conn = get_db_connection()
      cursor = conn.cursor()
      cursor.execute("""
          SELECT role, content, agent, created_at
          FROM conversations
          WHERE session_id = ?
          ORDER BY created_at ASC
          LIMIT 20
      """, (session_id,))
      
      for row in cursor.fetchall():
          role, content, agent, created_at = row
          conversation_history.append({
              "role": role,
              "content": content,
              "agent": agent or "系统",
              "created_at": created_at
          })
      
      conn.close()
      logger.info(f"[/api/chat] 加载历史消息: {len(conversation_history)} 条")
  except Exception as e:
      logger.error(f"加载历史消息失败: {e}", exc_info=True)
      # 不影响继续处理
  ```
- **修改2**: 调用 ResponseEngine 时传入 `conversation_history` 参数
- **状态**: ✅ 已完成

## 🔧 故障排查

### 如果历史未加载
1. 检查数据库是否有历史记录：
   ```sql
   SELECT * FROM conversations WHERE session_id='xxx';
   ```
2. 检查日志是否有"加载历史消息失败"错误

### 如果 AI 仍然健忘

## ⚠️ 注意事项

1. **失败不影响回复**：历史加载失败时，`conversation_history` 为空列表，不影响正常回复
2. **Token 控制**：通过滑动窗口 + Token 估算，避免超过 LLM 上下文限制
3. **性能优化**：历史查询限制 `LIMIT 20`，避免加载过多数据
4. **兼容性**：旧会话（无历史）仍能正常工作
